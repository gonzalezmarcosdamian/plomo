# El radar: sellos y artistas que se miran siempre

Estaban en `data/` como dos `.txt` sueltos, y `data/` es para JSONs de datos
personales que se regeneran. Esto no se regenera: son listas curadas a mano, o
sea criterio, y el criterio va en `rules/`.

**Ningun script las lee todavia.** Se usan a mano cuando hay que barrer novedades
(`scripts/muzpa_new_releases.py`, `scripts/muzpa_artist_scan.py`). Si algun dia
las lee el codigo, se pasan a JSON; mientras no, un `.md` dice mas.
